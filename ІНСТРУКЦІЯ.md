# 🐳 Розгортання OLX-бота на Hetzner через Docker

**IP твого сервера: `46.225.12.144`** (використовуй саме його для підключення)

---

## КРОК 1 — Підключення до сервера

### На Windows:
Завантаж **Putty** або використай вбудований термінал PowerShell:
```powershell
ssh root@46.225.12.144
```

### На Mac / Linux:
```bash
ssh root@46.225.12.144
```

> 💡 При першому підключенні погодься з fingerprint — напиши `yes` і натисни Enter.  
> Введи пароль від сервера (його надіслав Hetzner на пошту).

---

## КРОК 2 — Встановлення Docker на сервер

Виконай ці команди **на сервері** (по одній):

```bash
# Оновлення системи
apt update && apt upgrade -y

# Встановлення Docker одною командою
curl -fsSL https://get.docker.com | sh

# Встановлення Docker Compose
apt install docker-compose-plugin -y

# Перевірка що все встановилось
docker --version
docker compose version
```

Має вивести щось на кшталт:
```
Docker version 26.x.x
Docker Compose version v2.x.x
```

## КРОК 3 — Завантаження файлів на сервер

### Варіант А — через SCP (термінал на твоєму ПК, не на сервері):

```bash
# Спочатку створи папку на сервері
ssh root@46.225.12.144 "mkdir -p /opt/olx_bot"

# Завантаж всі файли проекту
scp -r ./olx_bot/* root@46.225.12.144:/opt/olx_bot/
```

### Варіант Б — через WinSCP (Windows, зручний графічний інтерфейс):
1. Завантаж WinSCP з офіційного сайту
2. Підключись: Protocol=SCP, Host=`46.225.12.144`, User=`root`
3. Перетягни папку `olx_bot` у `/opt/` на сервері

### Варіант В — вручну (якщо не хочеш копіювати файли):
```bash
# На сервері створи папку і файли вручну
mkdir -p /opt/olx_bot && cd /opt/olx_bot

# Для кожного файлу: nano назва_файлу → вставляєш вміст → Ctrl+O → Enter → Ctrl+X
nano bot.py
nano docker-compose.yml
nano Dockerfile
nano requirements.txt
nano config.json
```

## КРОК 4 — Налаштування config.json

```bash
cd /opt/olx_bot
nano config.json
```

Заміни два рядки:
```json
"bot_token": "ВСТАВТЕ_ТОКЕН_ВІД_BOTFATHER",
"chat_id": "ВСТАВТЕ_ВАШ_CHAT_ID",
```

### Як отримати токен бота:
1. Відкрий Telegram → знайди **@BotFather**
2. Напиши `/newbot`
3. Придумай назву і username (має закінчуватись на `_bot`)
4. Скопіюй токен — виглядає як `7123456789:AAHdqTcvCH...`

### Як отримати свій Chat ID:
1. Знайди в Telegram **@userinfobot**
2. Напиши `/start`
3. Він надішле число — це і є твій chat_id (наприклад `123456789`)

### Як додати свої фільтри OLX:
1. Зайди на olx.ua
2. Введи пошук, налаштуй ціну, місто, стан товару
3. Скопіюй URL з браузера
4. Вставте у `filters` у config.json

Збережи файл: **Ctrl+O → Enter → Ctrl+X**

## КРОК 5 — Запуск бота

```bash
cd /opt/olx_bot

# Збірка Docker-образу (перший раз ~1-2 хвилини)
docker compose build

# Запуск у фоні
docker compose up -d

# Перевірка що запустився
docker compose ps
```

Має показати:
```
NAME       STATUS    PORTS
olx_bot    running
```

Якщо все правильно — у Telegram отримаєш повідомлення:
> ✅ OLX-бот запущений! 🔄 Перевіряю кожні 10 хвилин

---

## КРОК 6 — Корисні команди для управління

```bash
# Переглянути логи в реальному часі
docker compose logs -f

# Переглянути останні 50 рядків логів
docker compose logs --tail=50

# Зупинити бота
docker compose stop

# Запустити знову
docker compose start

# Перезапустити (після змін у config.json)
docker compose restart

# Повністю зупинити і видалити контейнер
docker compose down
```

---

## КРОК 7 — Оновлення конфігурації (додати новий фільтр)

```bash
cd /opt/olx_bot
nano config.json    # внеси зміни
docker compose restart
```

## ❓ Часті проблеми

| Проблема | Що зробити |
|----------|-----------|
| `connection refused` при SSH | Перевір IP, можливо сервер ще не запустився після замовлення |
| `docker: command not found` | Повтори Крок 2 |
| Бот мовчить у Telegram | Перевір токен і chat_id у config.json |
| `ERROR: invalid reference format` | Перевір що ти в папці `/opt/olx_bot` |
| OLX не парситься (0 оголошень) | Перевір URL фільтра вручну у браузері — можливо він застарів |

## 📊 Моніторинг ресурсів сервера

```bash
# Скільки CPU/RAM використовує бот
docker stats olx_bot

# Розмір логів та даних
du -sh /opt/olx_bot/logs /opt/olx_bot/data
```

> 💡 Бот дуже легкий — використовує ~50 МБ RAM і мінімум CPU.  
> На найдешевшому Hetzner CX11 (2GB RAM) запустяться десятки таких ботів.
